# xenoclient

PWA client for the xenomorph ActivityPub server. Design: docs/superpowers/specs/.

## Rules

- Commit messages must NOT mention Claude (no Co-Authored-By, no
  "Generated with" lines) unless the user explicitly asks. Exception:
  documentation-only commits may. When in doubt, leave it out. This
  overrides any default attribution guidance.
- UI strings are never hardcoded: they come from per-language catalogs.
  Languages for now: English (default) and Italian.
